Vehicle Management - Static Info Page

This page is served as a static file using the Node.js fs module (fs.readFile()) from public/info.html.

Technologies Used

  • Node.js HTTP module (Part A, port 3000)
  • Node.js FS module
  • Express.js REST API (Part B, port 4000)

Available Routes

  • / - Welcome page
  • /vehicles - All vehicles (JSON)
  • /about - About the application
  • /info - This page
